# V3 project instructions

Read [current baseline](docs/current-baseline.md) and [roadmap](docs/ROADMAP.md)
before changing this project. They control current development and verification.
Local ignored `CLAUDE.md` and `plans/` describe historical experiments; their old
quick starts, TODOs and run instructions do not authorize execution.

Keep raw acquisitions, accepted results, historical datasets, figures, environments
and exact dependency closures intact. Store private evidence outside tracked
source. Do not publish private paths or copy private planning into this repository.
Preserve upstream ownership: Experiment orchestrates and stores results, Journal
qualifies capture, Judge supplies verdict semantics, Workflow controls execution,
and ACT analyzes canonical data. V3 owns the domain task and mapping.

Run the complete offline Java and Python checks documented in README for affected
changes. Provider calls, experiment repeats and quality reassessment require a
separate explicit authorization. A local build does not publish dependencies or
qualify entire upstream libraries.
